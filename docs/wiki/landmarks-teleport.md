# Landmarks, Home & Teleport History

> **Built** (headless-tested). Not yet tested on a phone. Works like Second Life's Landmarks, Set Home and Teleport History.

## Open it
MENU › **🧭 Teleport** (the panel is called *Travel to Landmarks*).

## Save a landmark
1. Stand where you want to come back to.
2. Tap **📍 Save landmark here**.
3. It shows up in the list as **📍 name · region**. Tap it to go there.

## Home
- Tap **⌂ Set home to here** to set your home.
- Tap **⌂ Go home** to go back to it.

## Teleport history
Your last 5 places are under **Teleport history**. The app keeps up to 50.

## When land says no
Land owners can switch off landmarks or Set Home. In MENU › **🏛 Region / Estate**, use **Allow landmarks** and **Allow Set Home**. Estate managers and the owner can still save there, like in Second Life.

## Other land switches
In **🏛 Region / Estate** you'll also find **Allow push**, **Show in search** and **Maturity** (general, moderate, adult). These are saved now, and the game will start using them as features land.

## Covenant
**Covenant (estate rules)** is a text box for the estate's rules. Only estate managers and the unlocked owner can edit it.

## Addresses
Every place has an address like `viper://Region%20M50/12/30/-8` (region, then x, y, z).
