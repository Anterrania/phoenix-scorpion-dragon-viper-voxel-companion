# Art licenses

- **Humanoid models (v0.3)**: original procedural geometry (`scripts/agent/humanoid_model.gd`), project-owned. No third-party mesh is bundled yet. A CC0 rigged base (e.g. Quaternius Universal Base Characters, CC0) is planned to replace the primitives.
- **Terrain, lava and sky shaders** (`shaders/*.gdshader`): original, project-owned. Detail comes from runtime FastNoiseLite, so no texture files ship.
- **Player references** (`art/references/player_phoenix/`): user-provided images made in the Grok app, for reference only and not shipped in the APK.
- **Voxel Tools** (Zylann godot_voxel): MIT license.
