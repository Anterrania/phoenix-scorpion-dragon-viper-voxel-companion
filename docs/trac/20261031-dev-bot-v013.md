## Reasoning
- **Ledger, not a blockchain.** LegalReview keeps `nft_blockchain` HARD. A local append-only hash chain gives
  tamper evidence (verify() finds the first edited record) without tokens, wallets or network.
- **Hash over a stored body string.** Godot's JSON turns ints into floats on reload, which would change a
  re-serialized hash. Each block stores its canonical body string and the hash covers that string.
- **Brain Cell lock.** "AI can't edit memories" is enforced by actor: `ai` writes are refused while locked (default),
  only an owner session can open a time-boxed window, anyone may lock. There is no edit or delete API — new
  versions supersede old ones, which stay readable.
- **Sparks, not Aethel payouts.** Paying creators in Aethel Coin would be a member-to-member coin transfer
  (`p2p_coin_transfer` HARD). Sparks are a separate earn-only credit with buy / cash-out / convert all HARD.
- **Scene snapshots** record only in-world events (realm/teleport/weather/companion join, Heaven edits); camera,
  mic, screen, GPS, contacts are refused by name.
- **Left out on purpose:** sexual/NSFW content (INT-NSFW stays blocked), real-world surveillance, any claim that
  the app is unhackable, removing safety gates/limits, real crypto/NFT, real-money Aethel exchange (LEGAL REVIEW).
