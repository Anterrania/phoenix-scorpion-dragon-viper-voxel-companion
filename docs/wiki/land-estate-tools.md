# Land & Estate Tools

## Land Tools (MENU › ⛰ Land Tools)
- **Raise, Lower, Flatten, Smooth, Noise, Revert.**
- Set **brush size** and **strength**.

## Region / Estate panel
- **Land texture** for the region or parcel.
- **Water height.**
- **Fixed sun** or hour.
- **Who can enter** and an allowed list.
- **Who can terraform.**
- Fly, build and damage switches.
- Parcel **music / media URL**.
- Saved on the phone.

## Heads up
- Access rules and media are saved, but enforced only once the server exists.
- **Who can terraform** and the **fly / build / damage** switches are saved, but this phone does not enforce them yet (audit 2026-10-17). Enforcement comes with roles and tiers ([BuildToolsAndTiers](../modules/BUILD_TOOLS_AND_TIERS.md)).
