# v0.16.0 (versionCode 22) — More ▾ top menu, Android notifications, quiet tests

## Changes
- Top bar: items that do not fit (any orientation) move into a "More ▾" dropdown that stays on screen, scrolls, and closes when you tap outside it. The old bar is commented out in ui_root.gd.
- Notifications: ViperDevicePlugin v6 adds channels (message, friend, live, announcement), `notify_permission`, `request_notify_permission` (Android 13+ POST_NOTIFICATIONS, asked once) and `post_notification`. SocialBridge.notify trims the text and refuses an empty title.

- Cleaner test output: SecureFile.quiet counts the deliberate tamper failures instead of logging errors; ciphertext checks decode as ASCII; the test PinPads and ring are freed; the unused `sec` VBox in _build_dest is commented out (it leaked 5 nodes per build).
- CI actions: upload-artifact v5→v7, checkout v5→v6, setup-java v5→v6 (the Node 20 deprecation warning).
- New tests/v016_tests.gd (44 checks).
