# MobiGlass-style UI

> **Future module, not implemented.** Phase: Phase 5. Design notes only.

A wrist-device holographic UI inspired by Star Citizen's mobiGlas (original design and name in-game).
- **Apps:** Chat (companions), Map/Star Map, Inventory, Build/Buy catalog, Needs & Mood, Relationships, Brain viewer, Quests, Settings (AI provider choice, offline toggle), Camera/Photo, Social share (drafts only).
- Built as a Godot Control scene rendered to a SubViewport on a wrist quad in 3D, with a flat 2D fallback on phones.
- Touch-first with large hit targets. Opens from a HUD button.
