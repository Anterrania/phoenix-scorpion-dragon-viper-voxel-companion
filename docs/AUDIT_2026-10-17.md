## 2. Dead, duplicate, unused and truncated code
Method: for every `scripts/**/*.gd` and `scenes/**/*.tscn`, count references by path and by `class_name` across `.gd/.tscn/.tres/.json/project.godot` (docs and the wiki seed excluded), then read each hit.

### 2.1 Bugs fixed (each has a test in `tests/audit_tests.gd`)
1. **Brain-cell revert skipped the owner gate.** `ViperAdminData._apply_brain_cell` (the Timeline "Hold to revert" path) wrote or deleted learned cells with no owner check, so a locked phone could change what a companion learned. Now returns `false` unless `EveCore.owner_ok()`. It also no longer crashes when the cells folder is missing (`FileAccess.open` returned null).
2. **`docs/TASK_TRACKER.csv` was imported as a translation.** Godot's default CSV importer made `TASK_TRACKER.task/.status/.priority.translation` and shipped them in the APK (seen in the v0.11 APK file list). Import is now `keep`.
3. **Wiki seed pages cut mid-sentence** (2 pages, above). `tools/export_admin_seed.py` now cuts on a line boundary and adds "(Shortened in the app at 24 KB. The full page is … in the repo.)".

### 2.2 Inactive code, commented out (not deleted)
Each file now starts with `# INACTIVE (2026-10-17): <what>, <why>, <re-enable when>`. Only the `extends` line stays live so the script-load tests still pass. All are excluded from export.

- **Release build** would use the release template and the release voxel library. Measured from the 4.7.2 templates: `libgodot_android.so` release is 71,114,944 bytes (24,023,949 deflated) vs debug 76,181,608 (27,838,354 deflated in the template). `libvoxel…template_release.arm64.so` is 7,301,800 bytes vs the editor build 9,031,288. So a signed release saves about 1.7 MB of voxel library plus about 1.4–3.8 MB of engine. APKs are Foxy's; this is a note for her release build.
- **Export filters (done):** Android and all scaffold presets now exclude `art/*, assets/concept_art/*, tests/*, docs/*, tools/*, patches/*, core/*, *.md`, the kit demo, and the INACTIVE prototype. Measured with `--export-pack Android`: **8,970,564 → 8,831,216 bytes (−139,348, −1.6%)**, 426 → 402 files. Removed from the pack: `ui_kit_demo.png` and `physical_form_concepts.svg` textures, the 3 junk translations, `main.tscn`, `kit_demo.tscn`, and 6 scripts.
- **Texture compression:** all 10 avatar textures use `compress/mode=0` (lossless). Switching them to VRAM (ETC2/ASTC) **was measured to make the pack bigger**: 8,831,216 → 10,846,416 bytes (+2.0 MB), because the 1024 px PNGs are small on disk. GPU memory drops from about 41.9 MB to about 10.5 MB (*calculated*: RGBA8 vs 8 bpp, with mips). It's a trade-off for Foxy after v0.12 (`patches/avatar_textures_vram_compression.patch`). Removing the duplicate eye texture saves 425,250 bytes in the APK.
- **Lossy WebP for UI:** there are no UI bitmaps (the UI is drawn in code and shaders); nothing to convert. **OGG for audio:** no audio files are bundled.
- **Mesh:** `mh_female.glb` is 7.9 MB in the repo but 859,337 bytes imported; it's already compact.
