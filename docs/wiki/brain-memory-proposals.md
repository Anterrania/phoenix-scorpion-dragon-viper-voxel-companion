# Brain, Memory & Proposals

## The idea
- Each companion has a **brain** that learns from you.
- It never changes itself without your OK.

## Memory
- Chats, builds, music and land changes are logged.
- Memory cells stay **locked** until the owner code is entered.
- Memory is stored on the phone.

## Teaching
- Say "when I say X, reply Y" to teach.
- Praise or "no, not that" adjusts the last reply.

## Proposals (approval gate)
- Open **MENU › 📜 Proposals**.
- New things a companion learned wait here.
- Tap **Approve** or **Reject**.
- Only the owner can decide.
- Learning runs every 2 minutes.

## Rollback
- Learned cells keep versions.
- In Proposals, tap **Roll back** to undo.

## History
- Open **MENU › 🕮 History**.
- Pick a companion (or yourself).
- Search the memory timeline.
- **Export** saves a portable file. **Import** merges it back.
- Export and import are owner-only.

## Not built
- Image, video and music "generation" is only logged. Nothing is made.
- Cloud backup of brains: **Planned**.
