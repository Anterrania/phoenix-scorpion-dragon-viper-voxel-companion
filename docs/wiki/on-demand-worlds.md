# On-Demand Worlds

- Regions **sleep** when nobody is in them and **wake** when someone arrives, in about 20 seconds.
- Estate managers can set **keep-awake hours** (for events) and an idle timeout.
- On a phone, up to 4 regions run at once. The emptiest, longest-idle one sleeps first.
- **Export a region** as a Viper region bundle: land settings, parcels and objects. It doesn't include people lists.
  - An object leaves only if you made it, it's full-perm, or its market listing allows export. The rest are listed in an export report.
- **Import** a bundle: owner only.
