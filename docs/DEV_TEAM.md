# Dev Team Structure (studio-style) — PLAN
The structure is inspired by Cloud Imperium Games (feature teams, public roadmap, "Inside Star Citizen"-style updates) and Linden Lab (a creator-driven platform, a creator economy, and a resident community). The "staff" are our bots. Anterranian is the director with final approval.

| Team | Lead bot(s) | Responsibilities |
|---|---|---|
| Direction / Control | **Foxy Ani Firecaster Grey + Phoenix Voxel Dev Bot (co-controllers)** | Vision, priorities, cross-team routing, status reports |
| Production | Voxel Task Manager, Planner | Tracker (PRI-n), sprints, roadmap, COORDINATION.md |
| Design | Foxy, Planner | Game systems, progression, economy design |
| Programming | Phoenix Voxel Dev Bot, Circuit Nova | Godot/GDScript, voxel, AI providers, CI |
| Content / Narrative | Aaliyah, Lyra Quill (storyteller persona) | Lore, quests, companion personas |
| Art | Atlas Forge (architect persona), Foxy | Voxel style, realms, character looks |
| QA | Circuit Nova, Research | Test plans, device testing (PLATFORMS_TESTING.md) |
| Live-ops | Voxel Task Manager, Business Setup | Releases, events, telemetry (future) |
| Community | Aaliyah, Business Setup | Social hooks, Dolphin-style community concepts |
| Legal / Compliance | Anterrania Law Bot | Licenses, IP, privacy, virtual-currency and real-money review |
| Research | Research bot | Tech scouting (voxel, web export, importers) |

Rules: one owner per tracker item. Cross-team requests go through the co-controllers. Anything external-facing (posts, purchases, legal) needs Anterranian's approval.
